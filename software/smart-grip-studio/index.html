06 / FAQ

Frequently asked questions.

What to know about compatibility, evaluation and commercial readiness.

Is Smart Grip Studio official OnRobot software?

No. It is an independent RoboQuo project intended for certain compatible OnRobot grippers. OnRobot has not endorsed or certified it.

Which grippers are compatible?

RG2, RG6 and 2FG7 are development and validation targets. Compatibility depends on hardware revisions, communication, Compute Box and software versions. Contact us with the exact setup.

Can I use it without internet access?

Offline gripper communication may be possible in a suitable local setup. Installation, licensing and offline operation have to be confirmed for the specific release; do not assume all functions work offline.

Does it automatically calculate a safe gripping force?

The planned force exploration helps compare grip settings in controlled tests; it does not establish a safety-certified value. Users must validate workpieces, payload, surface conditions and robot safety.

Can I download the trial or purchase a license now?

Not yet. This is a product preview. Evaluation builds, pricing, licensing and fulfillment require separate confirmation. No payment is collected through this page.

Is the graphical dashboard a screenshot of the software?

No. The displayed interface is an illustrative design preview with synthetic values. It must not be treated as verified measurements or an actual software screenshot.
