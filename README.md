# RoboQuo v12 — Trading Platform Prototype

This version restructures RoboQuo around a real marketplace business model:

- Browse freely without signup
- Email signup only when users inquire, bid or save
- Company verification concept for sellers and payouts
- Robot categories by application/type
- Robot makers and EOAT/gripper makers
- Used/new robot listings with fixed-price or bidding flows
- Company directory and Claim Profile concept
- Project bidding for teaching/installation/repair
- RoboQuo name story and operating principles
- EN / JP / KR / CN core languages
- Responsive mobile UI and PWA files

## Important
This remains a front-end prototype. Listings, bids and demo user state are saved only in the current browser via localStorage. To become a real multi-user service, the next step is a backend/database, authentication, shared file storage, company verification and payment infrastructure.
